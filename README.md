# My Portfolio

Personal portfolio website showcasing projects, skills, and contact details.

## Live Sections

- Hero section with animated wordmark and profile card
- About section with sticky service cards
- Projects section with horizontal slider
- Skills section with animated orbit carousel
- Contact call-to-action with direct email integration
- Footer with useful developer documentation links

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure

```text
portfolio/
├── index.html
├── styles.css
├── script.js
└── images/
```

## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Vinilnaik3705/My_Portfolio.git
```

2. Open the project folder:

```bash
cd My_Portfolio
```

3. Launch `index.html` in your browser.
